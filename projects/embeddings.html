Every dot is a 64 × 64 px Sentinel-2 chip, placed by its image–text embedding (UMAP). Type a description to find matching scenes, or click a dot to see its chip and generated caption.

Synthetic embeddings and chips. Export your own as JSON to replace them.
Find scenes by description

Approach

A dual encoder (image and text) is trained contrastively on Sentinel-2 chips paired with captions generated from land-cover labels and OpenStreetMap tags. Search ranks chips by cosine similarity between the text query and each image embedding. The 2D layout is a UMAP projection, used only for display.
