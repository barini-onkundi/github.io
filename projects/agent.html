Ask an analysis question in plain language. The agent plans the steps, calls GIS tools one at a time, and builds the map as it goes.

    Approach

    An instruction-tuned LLM gets a typed tool catalogue (geocoding, STAC search, raster algebra, vector overlay, routing) and returns JSON tool calls. A sandboxed executor runs each call on real data, and the result summary goes back to the model before it plans the next step.
